# 📚 Book Tracker 🔥

Book Tracker — это консольное приложение на Python, разработанное для учета и анализа личной библиотеки прочитанных книг. Приложение позволяет пользователям эффективно трекать свой читательский прогресс, оценивать книги и анализировать статистику по своим любимым авторам.

Проект демонстрирует чистую модульную архитектуру с разделением логики, хранения данных и пользовательского интерфейса.

## ✨ Основные возможности (Features)

*   **➕ Добавление книг:** Быстрый ввод названия, автора, рейтинга (1–5) и даты прочтения.
*   **🔢 Валидация ввода:** Строгая проверка формата дат (`ГГГГ-ММ-ДД`) и диапазона рейтинга (1–5) в момент добавления записи.
*   **🛡️ Анти-дубликат:** Предотвращает добавление книг, которые уже существуют в базе по автору и названию.
*   **📊 Статистический анализ:** Расчет общей средней оценки всех прочитанных работ и детализированный отчет по каждому автору (средняя оценка и количество книг).
*   **🗑️ Управление данными:** Возможность удалять записи из базы данных.
*   **💾 Persistency:** Все данные автоматически сохраняются в локальный файл `books.json`, обеспечивая их целостность при повторных запусках.

## ⚙️ Архитектура проекта (Modular Design)

Вместо того чтобы писать весь код одним большим файлом, мы разделили логику на модульные компоненты. Это делает код более чистым, тестируемым и масштабируемым.

| Модуль | Ответственность | Описание |
| :--- | :--- | :--- |
| **`main.py`** | 🖥️ **Контроллер (UI/UX).** Управляет пользовательским циклом: выводит меню, собирает ввод и вызывает соответствующие сервисы. | Точка входа приложения. |
| **`models.py`** | 📖 **Модель данных.** Определяет структуру объекта `Book` и методы для преобразования его между форматами (объект $\leftrightarrow$ словарь). | Гарантирует консистентность данных. |
| **`storage.py`** | 💾 **Доступ к данным (DAO).** Полностью изолирован от бизнес-логики. Отвечает только за чтение и запись в `books.json`. | Управляет файловой системой. |
| **`stats.py`** | 🧠 **Бизнес-логика.** Содержит математические расчеты (среднее, статистика по авторам). Работает исключительно с объектами `Book`, не зная о JSON. | Место для алгоритмов подсчета и анализа. |

## 💡 Как это работает? (Пример кода)

Функция `add_book` в `main.py` демонстрирует последовательный процесс сбора и валидации данных, прежде чем создать объект `Book`:

1.  Пользователь вводит название и автора.
2.  Система запрашивает дату (проверка формата).
3.  Система циклически запрашивает рейтинг (пока не будет число от 1 до 5).
4.  Если все данные валидны, создается объект `Book` с помощью `models.py`.
5.  Объект передается в `storage.py`, который проверяет на дубликат и сохраняет всё в файл.
